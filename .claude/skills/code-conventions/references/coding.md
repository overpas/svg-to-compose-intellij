# Coding

## General

- Don't edit the code that doesn't affect the task you are working on.
- Keep visibility of interfaces, classes, functions, properties minimal.

## Kotlin

When writing kotlin code use skills:

- /kotlin-control-flow
- /kotlin-api-design

When using kotlin concurrency features, coroutines, suspend functions, Flow, use
/kotlin-concurrency-and-flow skill.

## Compose

The UI is Compose for Desktop with Jewel inside the IDE.

When writing compose code always use skills:

- /compose-component-design
- /compose-state-and-effects

When working on animations in compose use /compose-animations skill.

When working on compose UI performance use /compose-performance skill.

When writing or reviewing Compose UI for keyboard, accessibility focus, FocusRequester,
focusProperties, key events, or initial focus behavior, use /compose-focus-navigation skill.
